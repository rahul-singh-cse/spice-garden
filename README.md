# Spice Garden 🌶️

A responsive restaurant website built with HTML, CSS and JavaScript.

## Live Demo
https://rahul-singh-cse.github.io/spice-garden/

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Features
- Clean and responsive design
- Restaurant menu and information
- Easy to navigate layout

## How to Run Locally
1. Clone the repo:
   `git clone https://github.com/rahul-singh-cse/spice-garden.git`
2. Open `index.html` in your browser.
