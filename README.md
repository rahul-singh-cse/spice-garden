# Spice Garden 🌶️

A responsive restaurant website built with HTML, CSS and JavaScript.

## Live Demo
https://rahul-singh-cse.github.io/spice-garden/

## Screenshots

![Home Page](screenshot-home.png)

![Menu Section](screenshot-menu.png)

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Features
- Responsive restaurant landing page with hero section
- Menu with category filters (Starters, Main Course, Drinks)
- Add to Cart functionality with live cart counter
- Clean and modern UI

## How to Run Locally
1. Clone the repo:
   `git clone https://github.com/rahul-singh-cse/spice-garden.git`
2. Open `index.html` in your browser.
